# Creature Feature

A REST API backend for managing customizable creature species, breeds, and procedurally generated animals. Species are defined with genetics, stats, and attributes. Breeds inherit from a species and can override genetic probabilities and stat ranges. Animals are generated from a breed using weighted random rolls across all of these systems.

## Tech Stack

- **Runtime:** Node.js with TypeScript
- **Framework:** Express
- **Database:** PostgreSQL via Prisma ORM
- **Validation:** Zod
- **Logging:** Pino
- **Testing:** Vitest + Supertest

## Data Model

**Species** — the top-level entity. Defines the gene pool, stats, and attributes shared by all breeds of that species.

**Gene** — belongs to a species. Has one or more loci, each with alleles. Expression rules determine what trait is displayed based on how many dominant alleles are rolled.

**Breed** — belongs to a species. Can override individual allele probabilities (`AlleleOverride`) and narrow stat ranges (`StatRange`).

**Animal** — belongs to a breed. Generated by rolling genes, stats, and attributes. Expressed traits, stat values, and attribute values are stored as JSON.

## API Routes

### Species
| Method | Path | Description |
|--------|------|-------------|
| GET | `/species` | List all species |
| GET | `/species/:speciesId` | Get a species |
| POST | `/species` | Create a species |
| PATCH | `/species/:speciesId` | Update a species |
| DELETE | `/species/:speciesId` | Delete a species |

### Breeds
| Method | Path | Description |
|--------|------|-------------|
| GET | `/breeds` | List all breeds |
| GET | `/breeds/:breedId` | Get a breed profile (merged with species data) |
| POST | `/breeds` | Create a breed |
| PATCH | `/breeds/:breedId` | Update breed fields |
| PUT | `/breeds/:breedId/overrides` | Upsert an allele probability override |
| PUT | `/breeds/:breedId/statRanges` | Upsert a stat range |
| DELETE | `/breeds/:breedId` | Delete a breed |

### Genes
| Method | Path | Description |
|--------|------|-------------|
| GET | `/species/:speciesId/genes/:geneId` | Get a gene |
| POST | `/species/:speciesId/genes` | Create a gene with loci and alleles |
| PUT | `/species/:speciesId/genes/:geneId` | Replace a gene |
| DELETE | `/species/:speciesId/genes/:geneId` | Delete a gene |

### Stats
| Method | Path | Description |
|--------|------|-------------|
| GET | `/species/:speciesId/stats/:statDefinitionId` | Get a stat definition |
| POST | `/species/:speciesId/stats` | Create a stat definition |
| PATCH | `/species/:speciesId/stats/:statDefinitionId` | Update a stat definition |
| DELETE | `/species/:speciesId/stats/:statDefinitionId` | Delete a stat definition |

### Attributes
| Method | Path | Description |
|--------|------|-------------|
| GET | `/species/:speciesId/attributes/:attributeDefinitionId` | Get an attribute definition |
| POST | `/species/:speciesId/attributes` | Create an attribute definition |
| PATCH | `/species/:speciesId/attributes/:attributeDefinitionId` | Update an attribute definition |
| DELETE | `/species/:speciesId/attributes/:attributeDefinitionId` | Delete an attribute definition |

### Animals
| Method | Path | Description |
|--------|------|-------------|
| GET | `/animals` | List all animals |
| GET | `/animals/:animalId` | Get an animal |
| POST | `/animals` | Generate a new animal from a breed |
| PATCH | `/animals/:animalId` | Update an animal |
| DELETE | `/animals/:animalId` | Delete an animal |

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create a `.env` file:
   ```
   DATABASE_URL="postgresql://user:password@localhost:5432/creature_feature"
   CORS_ORIGIN=http://localhost:5173
   ```

3. Run database migrations:
   ```bash
   npx prisma migrate dev
   ```

4. Start the server:
   ```bash
   npx tsx app.ts
   ```

## Testing

```bash
npm test
```

Tests use a separate database configured via `.env.test`.
